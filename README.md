# creative-type-svg

参考字体图片生成创意标题，并将黑白稿转换为可编辑 SVG。支持 Codex 和 Kiro，用户需要提前安装并登录的 Dreamina（即梦）画布CLI 或 LibTV CLI。

## 功能

- 用一张参考图生成指定文案的黑白创意字体
- 支持单条或批量文案
- 自动下载 PNG、转换 SVG 并打包
- SVG 可继续在 Illustrator 或 Figma 中编辑
- 默认不收集、不上传使用统计

## 使用前准备

1. 安装 Codex 或 Kiro 桌面版。
2. 准备已安装并登录的 Dreamina CLI 或 LibTV CLI。
3. 准备一张清晰的字体参考图和目标文案。
4. 将本仓库中的 Skill 安装到 Codex 或 Kiro。

本 Skill 不安装 Dreamina CLI。缺少所选 CLI 时，Agent 会提示具体缺失项。

## 安装

下载或克隆本仓库后，把仓库文件夹上传给 Codex 或 Kiro Agent，并发送：

```text
请安装我上传的 creative-type-svg Skill。
请根据当前软件自动选择正确的 Skill 安装位置，保留所有配套文件，避免重复嵌套。
安装完成后检查 SKILL.md 是否能被识别。
本次只安装和检查，不要生成图片，也不要消耗积分。
```

安装完成后重启软件或新开聊天即可。

## 快速使用

上传参考图，然后发送：

```text
使用创意字体转 SVG Skill。
参考我上传图片的字体风格。
标题：「双11我爱你」
比例：16:9
清晰度：2K
生成 1 张纯白背景、纯黑字体的黑白稿，并直接转成可编辑 SVG。
请提供 PNG、SVG 和预览。
```

## 批量使用

```text
使用创意字体转 SVG Skill，批量生成。
所有文案共用我上传的这张参考图的字体风格。
比例：16:9
清晰度：2K
每条文案生成 1 张纯白背景、纯黑字体的黑白稿，并直接转成 SVG。

文案清单：
1. 双11我爱你
2. 好价不等待
3. 今天就开抢

请逐条生成，最后打包 PNG 和 SVG。
```

也可以上传 UTF-8 TXT（每行一条文案）或带 `title` 列的 CSV。

## 默认模型

- **LibTV**：Seedream 5.0 Lite
- **Dreamina（即梦）**：Seedream 4.7

可以在指令中指定其他模型。没有特殊要求时，Agent 直接使用对应平台的默认模型；模型或参数不可用时会先说明，不会静默替换。

## 积分授权规则

- 平台确认扣除 **0 积分**：直接执行，不额外询问。
- 需要扣积分：Agent 会先说明平台、模型、数量和已知总费用，获得同意后才提交。
- 无法确认费用：先询问，不会默认免费。
- 重新生成、增加数量、提高费用或更换平台/模型：按新费用重新判断。

Codex、Kiro、网络、文件和登录权限弹窗仍可能需要用户操作。

## 输出文件

通常会得到：

- `PNG`：原始黑白稿
- `SVG`：可编辑矢量路径
- `ZIP`：批量文件包
- `batch-manifest.json`：批量任务恢复记录（如生成流程使用）

SVG 是轮廓路径，不是可以安装和输入汉字的字体文件。生成文字和路径仍需人工检查；复杂书法纹理可能需要在 Illustrator 中清理。
